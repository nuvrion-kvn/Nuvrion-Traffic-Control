# Обновление Nuvrion Traffic Control

Первый выпуск — 1.0.0. Проверяйте установленную версию командой `ntc --version`.

Скачайте `nuvrion-traffic-control.py` и `SHA256SUMS` из одного выпуска Nuvrion-Traffic-Control, проверьте `sha256sum -c SHA256SUMS`, затем следуйте установке в [README](../README.md). Сохраните конфигурацию и держите открытой консоль провайдера до проверки SSH и связи панели с нодой.

Автоматического переноса состояния другого проекта нет. Не включайте две независимые копии менеджера правил одновременно.
